# Feed-Forward Neural Networks (MLPs)

This project contains implementations and experiments with Feed-Forward Neural Networks (Multi-Layer Perceptrons - MLPs) for tasks such as classification and regression. It is part of my **self-study** journey compiled from various online and offline resources, aiming to reinforce understanding through practical coding exercises.

## Folder Structure

```
Feed-Forward Neural Networks (MLPs)/
│
├── Feed-Forward-Neural-Network.ipynb     # Main notebook with MLP implementation
├── Image-Classifier-MLP.ipynb            # Image classification using MLPs
├── Regression-MLP.ipynb                  # Regression model with MLPs
├── images/                               # Folder for plots or dataset samples (optional)
```

## Requirements

- Python 3.x
- Jupyter Notebook
- NumPy
- Matplotlib
- TensorFlow or PyTorch (depending on notebook)
- scikit-learn
