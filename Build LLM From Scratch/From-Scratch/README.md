# Build LLM From Scratch

This repository is a personal self-study and experimentation space where I compile what I’ve learned about building **Large Language Models (LLMs)** and **Foundation Models (FMs)** from scratch.

It includes code, notes, and notebooks covering core concepts such as tokenization, data loading, attention mechanisms, transformer components, and training workflows.

The learning material is synthesized from multiple sources, including but not limited to:
- Sebastian Raschka’s *“Build a Large Language Model (From Scratch)”*
- Unsloth continued pretraining and instruction-tuning notebooks
- Additional papers, tutorials, and hands-on experiments encountered along the way

The goal of this repo is **understanding through implementation**, not production-ready code.
