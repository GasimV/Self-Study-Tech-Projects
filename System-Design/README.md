# System Design

This repository documents my self-study journey in system design. It contains notes, examples, exercises, and key takeaways focused on building scalable, reliable, and high-performance software systems.

## Books

- [System Design Guide for Software Professionals](https://learning.oreilly.com/library/view/system-design-guide/9781805124993/) — Dhirendra Sinha and Tejas Chopra
- *System Design: A Guide to Building Scalable, Reliable, and High-Performance Systems* — Amardeep Vishwakarma

## Topics Learned

- Functional and non-functional requirements, capacity planning, and design trade-offs
- High-level architecture, low-level design, data flow, APIs, algorithms, and data structures
- Scalability, performance, latency, availability, consistency, and cost optimization
- Database modeling, indexing, replication, partitioning, sharding, and distributed consensus
- Load balancing, caching, CDNs, traffic routing, and auto-scaling
- Microservices, asynchronous messaging, event-driven systems, and resilience patterns
- Security, fault tolerance, observability, incident response, and production operations
- End-to-end design of real-time, high-throughput, and distributed applications

> This repository is for personal learning and reference.
